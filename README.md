# Amazon-product-analysis-

## Project Overview
This project analyzes Amazon product data using Python to discover insights about product pricing, discounts, customer ratings, and categories.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights

## Key Insights
- Most product ratings are between 4.0 and 4.4.
- Higher discounts do not necessarily result in higher ratings.
- Electronics and Computers & Accessories contain the largest number of products.

## Business Recommendations
- Focus on product quality rather than relying only on discounts.
- Promote highly rated categories.
- Monitor customer feedback to improve customer satisfaction.

## Conclusion
This project demonstrates the complete data analysis workflow from data cleaning to business insights using Python.
